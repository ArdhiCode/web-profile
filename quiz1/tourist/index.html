04 — Tempat untuk dikunjungi

Jelajah sudut Bojonegoro.

Dari sumur minyak bersejarah sampai api abadi dan waduk di antara perbukitan.

Foto: Pemerintah Kabupaten Bojonegoro via Wikimedia Commons · domain publik

Periksa jam kunjungan dan kondisi lokasi sebelum berangkat, terutama saat musim hujan.

Tiga tempat untuk mulai

01

Wisata Migas Wonocolo

Kawasan penambangan minyak tradisional di Kecamatan Kedewan yang memperlihatkan sejarah dan aktivitas migas Bojonegoro.

02

Kayangan Api

Fenomena api abadi di Kecamatan Ngasem, dikelilingi kawasan hutan jati dan menjadi salah satu tujuan wisata alam Bojonegoro.

03

Waduk Pacal

Waduk di Kecamatan Temayang dengan suasana perairan dan perbukitan, cocok untuk menikmati pemandangan alam.
